# 🎮 Gamevault

**Gamevault** is a game discovery platform where users can explore, search, and discover video games. It provides useful information about games, including prices, descriptions, store details, and YouTube videos.

## ✨ Features

- **Explore Games:** Browse and discover a wide collection of video games.
- **Search Games:** Easily search for your favorite games.
- **Game Store:** View game store information, pricing, and other details.
- **Game Details:** Get detailed information about individual games.
- **YouTube Videos:** Watch related YouTube videos directly from the game details page.
- **API Integration:** Fetch game information and related data dynamically using an external API.

## 🛠️ Technologies Used

- React.js
- HTML5
- SCSS
- JavaScript
- External API Integration

## 🚀 Getting Started

### Run Locally

1. Clone the repository:
   git clone https://github.com/rhlydv216581/Gamevault

2. Navigate to the project folder:
   cd Gamevault
  

3. Install dependencies:

 
   npm install
 

4. Start the development server:


   npm run dev


5. Open your browser and visit:


   http://localhost:5500


## 🔑 API Integration

Gamevault uses an external API to retrieve game information, pricing, store details, and related content.
